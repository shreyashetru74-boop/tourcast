        How the test works, and every result

        For each artist, Tourcast planned a 5-city tour using only the three artists Qloo rates most similar to them, never the artist's own data. Those cities were then ranked against the artist's own Qloo fan map, and compared with a biggest-cities tour and a random one scored the same way.
